A collection of notes, screenshots, and decoding work for the Bub & Frend ARG.

## Contents

- **General Info:** running list of observations and cross-episode connections
- **Eyes Translations:** the letter-to-number table and the decoded eye sequences
- **Room:** notes on the clickable eye room and how its folder requests work
- **Characters:** Bub, Frend, Bub's dog Pancake, and Frend's dog painting
- **Episodes:** one note per episode, 1 to 17, with screenshots

## How to use this

**Option1: Using the [github repo](https://github.com/AvanishKhachane/BubAndFrendARG) directly**

**Option 2: Open in Obsidian**

1. Open Obsidian and choose **Open folder as vault**.
2. Select the `BubAndFrend` folder.


**Option 3: Open locally (no install needed)(not recommended)**

1. Unzip `BubAndFrend_WebsiteVersion.zip`.
2. Double-click `index.html`.

The site opens in your browser. Use the sidebar to navigate. Links between notes and all images work offline.(this will be updated way less frequently so obsidian is recommended)


Wiki-links and embedded images work as they do in the original vault.

## Notes

- Images are in the `zimages` folder. Keep that folder next to the notes so the links don't break.
- Some pages reference screenshots that aren't included in this vault. Those spots show a placeholder message.
- Decoded words are based on the eye-binary table. Entries marked `?` are still unknown.

## Status

Open questions are listed in General Info and Eyes Translations. Corrections and additions are welcome.
